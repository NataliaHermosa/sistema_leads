# 🚀 Sistema de Gestão de Leads - Gov Academy

Sistema completo para gestão de leads com dashboard, cadastro e relatórios.

## ✨ Funcionalidades
- 📊 **Dashboard** com métricas em tempo real
- 📝 **Cadastro** de novos leads
- 👥 **Lista e edição** de leads
- 🔍 **Busca avançada** em todos os campos
- 📈 **Relatórios visuais** com gráficos interativos
- 🏷️ **Tags e classificação** de leads

## 🛠️ Tecnologias
- **Python 3.9+**
- **Streamlit** - Interface web
- **Google Sheets API** - Banco de dados
- **Plotly** - Gráficos interativos
- **Pandas** - Manipulação de dados
